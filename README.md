# Customer-Churn-PwC

## Overview
This project explores customer churn behavior through exploratory data analysis (EDA). The goal is to understand the key drivers behind customer attrition and surface patterns that can inform retention strategy. The analysis was developed as part of a PwC-related data analytics exercise.

## Contents
- `churn_eda_v2.ipynb` - Jupyter notebook containing the exploratory data analysis, including data cleaning, univariate and bivariate exploration, correlation analysis, and visualizations of churn patterns across customer segments.

## Objectives
- Understand the overall churn rate and how it varies across customer attributes (tenure, contract type, payment method, services subscribed, etc.)
- Identify features that show the strongest association with churn
- Visualize trends and distributions to support business recommendations
- Lay the groundwork for future predictive modeling of churn risk

## Tools & Libraries
- Python 3
- Jupyter Notebook
- pandas, numpy for data manipulation
- matplotlib, seaborn for visualization

## Getting Started
1. Clone this repository
2. Install the required dependencies (pandas, numpy, matplotlib, seaborn, jupyter)
3. Open `churn_eda_v2.ipynb` in Jupyter Notebook or JupyterLab
4. Run the cells in order to reproduce the analysis

## Status
This repository currently contains the exploratory analysis phase of the project. Future updates may include feature engineering and predictive modeling.
